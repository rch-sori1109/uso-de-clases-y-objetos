# Clases y objetos

## Explicación del programa

Este programa nos permite registrar y visualizar información de libros exactamente. El programa nos ayuda a gestionar colecciones de libros, de manera sencilla y organizada, tenemos que ingresar los datos básicos, como el título, el autor, el año, la edición y la cantidad de páginas, el sistema creará un registro completo y lo mostrará en pantalla con un formato claro y profesional.
